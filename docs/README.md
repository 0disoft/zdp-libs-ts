# Docs

`zdp-libs-ts` docs separate shared TypeScript contract metadata from product-specific behavior.

## Contracts

- `contracts/package-boundary.md`: public exports and package scope
- `contracts/api-handoff.md`: `zdp-api-contracts` source handoff
- `contracts/glossary.md`: common glossary source and locale copy rules
- `contracts/security-contracts.md`: env, event, error, i18n, and glossary sensitive-data limits

상위 실행 기준은 `VALIDATION.md`를 따른다.
